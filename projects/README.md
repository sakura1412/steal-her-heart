# 可选研究项目

此目录用于用户主动选择的长期项目。默认竞品研究直接在 Codex 中开展，无需项目配置。

项目按实际需要保存 profile.md、dimensions.md、competitors.md 和版本记录；流程见 [项目说明](../codex-skills/steal-her-heart/references/projects.md)。可从 [背景模板](../templates/profile.md) 开始；背景不必一次填完，未知项明确保留。已有文件先读取，不自动覆盖或迁移。

本目录的实际业务项目保持本地，不默认提交。研究成果按需保存在工作区 research 目录并保留版本。只有真正写入并检查的文件才能提供交付链接。

## 如何补齐真实验证

对每个将要交付的 Adapter 或 IndustryPack，先建立具备版本和范围的实际实例，再用公开或获授权材料测试成功路径、拒绝访问、缺数据、时效和语义边界，记录输入、工具结果、输出及限制。没有实例时保持 `not_run_no_instances`，不凭模板填一份 passed。

分析方法的下一层是用真实对象、已核验证据和明确问题逐项执行，并由独立评审检查反例、口径与结论支持。任何新增验证都绑定 method_id／version／定义指纹；现有受控案例结果不能自动继承给改变过定义的方法。当前没有声称已提供自动评估器、全站连接器测试或专业行业认证。

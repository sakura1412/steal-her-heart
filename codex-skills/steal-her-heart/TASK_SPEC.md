# Codex Agent 运行职责与任务管理

本文件定义 Codex 执行研究时的职责和可观察结果。步骤记录是研究进度，不是自动运行系统或已经完成的证明。

## 最高级设计与本轮优先级

[三项原则](references/architecture.md) 约束全部职责与扩展。统一入口是 [Competitive Intelligence Subject](references/subjects.md)；十类任务共享一个引擎。P0 [Comparison Engine](references/comparison.md) 是跨对象比较和评分的前置准入；[Analysis Method Registry](references/analysis-methods.md) 与 [Market Intelligence](references/market-intelligence.md) 消费同一套可比性与证据规则。契约属于 Codex 执行规范，不表示独立服务已部署。

## 职责与交接

| 职责 | 输入 | 输出与完成标准 | 权限边界 |
|---|---|---|---|
| 主控 | 用户请求、当前范围、结果与限制 | 下一动作、进度、停止／恢复说明 | 不代用户批准，不自行编研究事实 |
| Entity Resolution | 原始名称、上下文、身份材料及旧映射 | 实体标识、层级、别名候选、关系证据与未决歧义 | 不按名字强合并、不推断无证所有权、不自动扩研究范围 |
| Planner | Subject、问题、约束、行业包与缺口；取证后另接当前 QA 及实际数据 | 动态框架、有界任务；QA 后的 method_id／版本、选择理由与输入检查 | 候选不等于必跑方法，缺输入补证，不擅自扩范围 |
| Discovery | 明确发现请求、种子与画像依据 | 消歧去重的候选、关系标签和分类依据 | 候选不等于获准开展完整研究 |
| Connector Selection | 研究问题、Registry 约定、当前工具与授权 | 本次来源／模式／适配条目、能力限制、实际验证记录 | 不注册虚假工具，不把声明当接入成功 |
| Research | 独立研究问题、对象、字段、来源限制与连接器条目 | Raw Data、标准化候选、完成与失败记录 | 不自称证据已核验，不新增任务；Normalizer 不补造事实 |
| Validator | 当前范围和证据候选 | 支持判定、冲突、覆盖与补证缺口 | 不为通过而删必需问题 |
| Comparison | 已核验证据、对象层级、指标定义、目标情景 | 可比组、标准化记录、状态矩阵、可选评分和图形数据及追溯 | 不强行分组、补零或跨组排名 |
| Analysis | 已核验证据、决策问题、比较口径及已校验的可选指标／方法版本 | 比较、结论、机会及验证建议 | 新结论仍需检查证据支持 |
| Reporter | 核对后的分析、显式或默认的角色与报告类型、格式偏好 | 对应详略的草稿、来源映射及经检查的 PDF；明确需要时另交 PPT | 不新增事实或策略 |
| Report QA | 完整草稿、范围和证据 | 九项检查及定位到责任步骤的问题 | 不以自评分数代替核查 |

这些是同一 Agent 的工作职责，不要求每项启动一个独立代理。需要拆分且当前环境允许时，Worker 按独立研究任务接收对象、问题、权限、完成条件和投入限制；隔离上下文，结果先核验，再汇总。竞品名称不是唯一派发单位。

## 任务记录

研究记录按 [台账与检查点](references/research-ledger.md) 及其 JSON Schema 落盘；PDF 和 PPT 各自从同一输入快照生成，不互相转写。质量判定按 [阈值与预算](references/research-quality.md) 执行，调用前预留、返回后对账，返工有上限。

复杂研究记录：任务标识、原始问题、对象 entity_id／身份版本与必要关系、范围版本、选中维度与必需性、读者问题、报告类型及选择依据、输出格式、PPT 意愿、文件路径与导出检查结果、材料时点、当前进度、任务清单、已用投入、缺口、下一动作和保存位置。

每个子任务注明问题、依赖、结果定位、状态和失败原因。区分待开始、执行中、待输入、暂不可执行、已取得材料、核验通过、失败、取消；取得材料不等于核验通过。

研究进度依次为 Subject 理解、动态规划、Adapter 取证、证据核查、覆盖／缺口检查、必要补研、Planner 方法选择、需要时可比组准入、分析与新结论核查、报告、报告检查、完成。等待只用于具体未决信息或确认；补研回规划，报告问题回其根因步骤。完成必须有实际结果和质量检查；取消、失败、受阻不能记录为完成。

## 版本与增量

保存范围版本及改变原因；实质变更说明哪些对象／问题、证据、比较和报告受影响。新对象只补相关任务，新增维度只补适用缺口；旧有效事实不重复采集。

仅排版变化重新检查报告；新决策问题需要重新分析和核查结论；新事实需求才补研。旧报告保留，更新说明列新增、改变、复用及未解决项。恢复不把迟到的旧范围结果直接合并进新版。

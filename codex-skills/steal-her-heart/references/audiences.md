# 读者与交付

角色是决策视角，先将关注点转为分析问题，再从共同事实形成相应结论；交互与交付统一遵循 [report-delivery.md](report-delivery.md)。

| 读者 | 重点 | 产物 |
|---|---|---|
| 产品经理 | 任务覆盖、能力差距、趋势相关性、机会取舍 | 可比矩阵、机会与验证建议；我方路线图需我方背景 |
| 销售领导 | 竞争场景、价格条件、资源选择 | 优先场景与风险；真实赢输需授权记录 |
| 一线销售 | 客户选择条件、异议依据与比较边界 | 一页销售卡、探测问题、禁说项 |
| 运营 | 渠道、内容、活动、引导与持续服务 | 增长假设与实验建议，不编效果数据 |
| 管理层 | 决策价值、主要机会与风险、选择条件与投入取舍 | 决策摘要及验证建议，不虚构财务收益 |
| 通用读者 | 核心结论、基本依据与适用边界 | 易读概览与必要对比 |
| 自定义角色 | 用户明确的决策问题 | 按关注点与格式输出 |

销售一页纸可包含对方主要卖点、客户可能表达、我方有依据的回应、差异化优势、探测问题与不能说的话。数量以证据为准，不为凑三个卖点或优势编造；假设话术不伪装真实引语，探测问题不预设未证实缺陷。没有我方背景时仅整理对方事实与待补问题。

即时简报标明对象、资料时点、内容窗口与未解决项。“周报／月报”只表示本次内容窗口，不能自动创建后续监测。多角色输出共用来源和事实版本；新增问题如需新事实，再安排对应补证。

# /analyze 竞品名

这是默认入口。接受 `/analyze 名称`、“帮我分析名称”或上下文明确的裸竞品名称。`$ARGUMENTS` 表示实际研究对象，不是项目名或可执行代码；没有名称或只收到字面占位符时，仅询问要分析谁。

用户不必拥有产品，也不必提供我方背景、行业、项目名、市场、读者或目的。不要启动十一题访谈，不创建 default 项目，不要求先运行 `/init-project`。裸名称可由 Codex 根据上下文理解；Python 路由只支持明确命令和现有自然语言句式，不把任意文本猜成竞品。

## 1. 识别对象，只澄清必要歧义

保留用户原名。结合本次官方来源检索识别产品、公司、品牌或服务；同名实体确有歧义时，给简短选项，或仅问官网／行业等能消歧的一项。明确对象时直接继续，不询问“你的产品是什么”。

用户附带的关注点、地区、读者或时间要求直接采用；未提供就按通用竞品概览研究，并在输出中声明实际覆盖范围。来源中的地区、版本、币种和日期逐条记录，不把某地区报价冒充全球统一价格。

纳入近期动态时说明本次观察起止日期；用户未给时间范围，可选择并声明有限窗口，不冒充用户要求，也不承诺穷尽该时间内全部事件。

## 2. 自动设计适合对象的维度

读取 [library/dimensions.md](../library/dimensions.md)，根据检索确认的行业与交付方式选择核心字段和适用扩展。通常覆盖定位与客群、核心产品或服务、价格与商业模式、公开价值主张、口碑、近期动态和适用边界；不是所有对象都要研究 AI、API、移动端或软件版本。

简述将研究的方向并继续执行，不把这一步变成等待用户确认的初始化门槛。目的与读者省略时不阻塞，也不把 Agent 的默认选择记成用户已提供的偏好。无法确定行业时先以通用字段查证，不靠训练记忆补事实。

本次只研究用户指定对象。其他品牌可以作为有来源的背景提及，但不能自动扩成多竞品采集任务。只有实质扩大对象、地区或研究范围时才询问；同范围查证和补证无需重复确认。

## 3. 真实联网、取证与核查

使用当前宿主实际可用的搜索和网页读取工具。优先官网、产品／服务说明、公开价格、文档与公告，结合可访问的第三方资料和用户反馈。打开支持主张的来源页面；搜索摘要只作线索。记录来源链接、获取日期、来源类型、适用口径和置信度依据；发布日期未知留空，不用获取日期替代事件日期。

事实、官方宣称、样本反馈与分析判断分开。核查时效、冲突、同源转载和遗漏；有缺口时在同一范围内补证。未查是“未采集”，完成查找无结果才写“未找到”，访问失败单独披露。功能没被提及不能直接判为没有；一条评价不能代表普遍体验。

联网工具不可用时如实说明，最多提供待研究提纲和缺口；不能把本地词表、训练记忆或伪造链接包装成已经完成的分析。

## 4. 形成通用研究报告

默认输出以下内容，可按对象调整深度：

1. 对象身份、研究范围与获取日期。
2. 定位、客群、核心产品／服务与交付方式。
3. 价格／商业模式及地区、版本等适用条件。
4. 有依据的差异化特点、适用边界、口碑和近期动态。
5. 研究结论、证据不足之处，以及下一步建议验证的问题。
6. 来源目录，保留重要冲突与限制。

没有我方背景时，不编写“我们领先／落后”“我方三个杀手锏”“赢单／丢单原因”或“对我们意味着什么”。可给一般性的学习点和待验证假设，但不能虚构用户所在行业、客户、优势或需求。用户要求我方对比时，只补问完成该对比必需的信息；项目初始化仍可选。

用户请求 Battlecard 时，可先复用竞品画像；在我方回应、优势或赢输判断之前，仅询问我方产品和相关场景等必要背景。用户不提供时标明这些区块的缺口，不强制补全整个 profile。周期简报另需明确周期与已有研究资产范围，不要求我方产品。

## 5. 保存与交付

只有实际生成内容后才保存到 `research/<安全对象标识>/<本次运行标识>/report.md` 和 sources.md，避免覆盖已有版本。文件名由应用生成，不将原始名称当作路径或 shell 代码；拒绝跨目录写入。这里的对象目录不是“我的产品项目”，不需要 profile.md。复用旧资产前重新检查时效，易变事实本次核验。

结尾给出报告与来源文件链接、获取日期和关键限制。未联网、未核查或仍有未解决缺口时，不声称完成完整研究。

## 当前实现边界

本指令由 Codex 使用宿主工具执行，不代表 Python 已具备研究引擎。Python 单名 `/analyze` 可无项目解析并返回 pending_module；run 可保存无项目任务并停在 UNDERSTANDING。搜索、网页采集、实质核查、分析和报告生成尚未接入 Python，不会因路由成功就产生报告。

若用户主动选择项目模式，按 [init-project.md](init-project.md) 建立可选背景；只在显式选择项目时读取对应 profile、维度及有效批准。现有项目 review API 保留原有范围绑定与锁检查，不能伪造 ProjectContext 或锁文件来运行默认分析。
